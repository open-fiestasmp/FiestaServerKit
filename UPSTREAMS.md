# plugin source links

The inventory records jars found on Fiesta. These links point to project source or publisher pages, not to Fiesta's private configuration. Download each plugin from its publisher and check its license and version compatibility. No third-party jars are included in this repository.

Links were checked on 2026-11-24. Where the jar declares a website, the link follows that metadata. A similar name alone is not enough to identify a plugin.
