# MiniMOTD example

Copy `main.conf.example` to MiniMOTD's `main.conf` in its plugin configuration folder. If you keep `icon=server-icon`, add your own 64×64 PNG as `icons/server-icon.png`.

`max-players` changes the number shown in the server list. Set the real admission limit in the server and proxy settings. This example does not advertise fake players.
